# mm-skill

[中文](README.md) | **English**

> **NOTE: The code for this project is generated by AI and has not been carefully reviewed manually!**

A user-level skill wrapping the [mm](https://bhosmer.github.io/mm) 3D matmul visualizer (`github.com/bhosmer/mm`), so the assistant can build and drive 3D visualization pages (attention, MLP chains, blocking, algorithms) during guidance sessions. mm renders matrix multiplications, attention, and MLP chains as interactive 3D cubes.

## Layout

The repository root holds the project docs and the maintenance script; the skill itself lives in `skills/mm-skill/` (install by copying or linking this directory into the skills directory of your agent host - e.g. `~/.claude/skills/`, `~/.qoder/skills/`, `~/.agents/skills/`, or a project-local skills directory).

## Quick start

Just ask the assistant for something like "build a **causal attention** 3D visualization with mm". It will:

1. copy a template into your project's `.mm-viz/` directory and configure the params;
2. **start the local server automatically in the background** (`serve.py`, default port 8019 - no manual action needed);
3. hand you the preview URL `http://127.0.0.1:8019/viz/<name>.html` (index at `http://127.0.0.1:8019/`).

The generated pages and the index are bilingual (zh/en) - switch via the button at the top right (follows the browser language by default and remembers your choice).

Manual try (optional; the server is started automatically by the AI during normal skill use):

```bash
# Replace $skill with the skill directory (skills/mm-skill in this repo, or the installed skill dir)
skill="C:/path/to/mm-skill"

# 1) Copy a template into .mm-viz (example)
mkdir -p .mm-viz
cp "$skill/templates/viz-interactive.html" .mm-viz/demo.html

# 2) Start the server (run from your project directory)
python "$skill/scripts/serve.py"

# 3) Open in the browser (pick your platform)
#    Windows:  start http://127.0.0.1:8019/viz/demo.html
#    macOS:    open  http://127.0.0.1:8019/viz/demo.html
#    Linux:    xdg-open http://127.0.0.1:8019/viz/demo.html
```

Server options: `--port 8020`, `--viz-dir /path/to/vizzes`, `--host 0.0.0.0` (LAN access).

## Online & offline modes

| Mode | URL | Description |
| --- | --- | --- |
| Online (default) | `https://bhosmer.github.io/mm/index.html` | Uses the original project's GitHub Pages service |
| Offline | `runtime/mm/index.html` (served by `serve.py`) | Ships the complete mm file set (1.8MB); fully offline |

One-click switching within the page (or append `?src=local` / `?src=online` to the URL).

> Note: offline mode relies on the local server; during normal skill use it is started automatically in the background - no manual action needed.

## Update the vendored runtime

The vendored runtime lives in `skills/mm-skill/runtime/mm/`. Use the repo-level script `scripts/fetch_mm.py` to re-download/update it (direct connection by default, no proxy; set a proxy via `--proxy` or the `MM_PROXY` env var if needed):

```bash
python scripts/fetch_mm.py                           # direct connection (default, no proxy)
python scripts/fetch_mm.py --proxy http://host:port  # via an HTTP proxy
```
